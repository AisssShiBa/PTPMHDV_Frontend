# Frontend workspace scaffold

- The existing Vite web app remains at the repository root; no app files were moved.
- `apps/mobile` is the workspace placeholder for N6d.
- `packages/api-client` and `packages/api-contract` are placeholders for N6b.
- npm workspaces are configured for `apps/*` and `packages/*`.

Run the existing web app from the repository root with `npm run dev`.
Mobile and shared package workflows will be documented with their implementation in N6b and N6d.
